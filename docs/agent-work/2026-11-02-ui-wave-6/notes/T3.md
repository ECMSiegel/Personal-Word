# T3 -- scissor, comment and toolbar icon rendering

## Plan

- `paragraphRange(state)` returns the non-empty selection, otherwise the current textblock's content range, or null for an empty block.
- With a collapsed cursor in text, Comment and Keep as fragment select the full paragraph before invoking their existing App callbacks. Empty paragraphs keep both actions disabled.
- The scissor joins the existing toolbar dock; SVG drawing size becomes 24 px and is scaled down at rest so peak hover draws at scale 1 without moving the toolbar layout.
