| Asset staging vs content commit | `post-asset-stage` (staged bytes committed, no edit uses them) | project, history and `project.json` equal the pre-stage state exactly (atomic visible state); the staged image row is present and byte-exact; only the referenced images are attached | the staged bytes read back; the edit that references them commits; image attached; mirror and history exact | staged row lost; staged bytes corrupted; content visible though never committed; attachment missing after recovery; commit lost |
