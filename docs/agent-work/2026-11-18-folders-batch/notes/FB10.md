# FB10 — Research bar source reordering

## Change

- Added pointer drag reordering to research source rows, limited to the `.source-toggle` row so interactions in an expanded source body do not start a drag. A completed drag suppresses the toggle click.
- Added Option+Up / Option+Down reordering for focused source toggles, with a polite live announcement and focus restored to the moved source.
- Wired `ResearchPanel.onReorderSources` through `App` to the existing `reorderResearch("sources", id, to)` mutation. The same project source order feeds the sidebar.
- Reused the existing `useDragReorder` hook and its drag-reorder styles.

## Fail-first

Before the implementation, the built-preview regression spec failed for the expected behavior: dragging Source Gamma above Source Alpha left the panel in its original order. The assertion expected `Gamma, Alpha, Beta` and received `Alpha, Beta, Gamma`.

- Command: `PLAYWRIGHT_PREVIEW=1 PLAYWRIGHT_PORT=1420 npx playwright test tests/fb-research-drag.spec.ts --workers=1 --trace off --output test-results/fb-FB10-fail-first`
- Full output: `node_modules/.cache/personal-word-beta/fb10-fail-first.log`
- Result: 1 failed at the expected source-order assertion (not a setup or selector failure).
