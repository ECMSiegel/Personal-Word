# FB12 -- Real page view for Read and Bibliography (board T330)

Status: CLAIMED (Chromium dev-server evidence only; owner hand check in the Mac app still open).
Whole-paragraph fallback: NOT used. Paragraphs split between lines (the spec asserts at least one
spacer inside a paragraph in Read and that no text line crosses a sheet's margin edge).

## What changed
- `src/editor/staticPagination.ts` (new): `measureStatic(surface)`, `paginateStatic(surface, geometry)`
  as in the Interfaces, plus `unpaginateStatic(surface)` (the removal step, exported for the test).
  Blocks = direct children of the surface (spacers skipped); headings = h1-h3 and `.read-title`;
  only `<p>` reports lines. Rect-vs-zoom scale detection copied from `measure()`. All insertion
  points are found before any spacer is inserted, and inserted last-first so two splits in one text
  node keep their offsets. Spacers are `span.page-spacer[data-static]` (`data-split` when a text node
  was split). Deviation: instead of `normalize()` on the parent, removal joins exactly the two text
  nodes it split (`appendData` into the original node). `normalize()` would also merge text nodes
  React rendered separately (e.g. `{title}{" "}`), breaking React's node references; the join keeps
  the original node, so the DOM equals the original exactly (unit-tested).
- `src/editor/pagination.ts`: `glyphLines` exported (no other change).
- `src/components/PagedSheet.tsx` (new): the Interfaces component. `div.editor-viewport.is-paged.paged-sheet`
  > `div.editor-paper` (zoom = fit) > `.page-sheet` per page + `PageLabels` + `div.writing-surface`
  keyed by `contentKey`. Repaginates in a layout effect on mount / contentKey / fit change, after
  `document.fonts.ready`, and on any `<img>` load inside (capture listener). Fit = min(1, available
  / page width) from a ResizeObserver on the viewport (never the surface). `--footnote-reserve` 0.
- `src/components/paged-sheet.css` (new, budget 0): desk background and column width for the two
  screens in page view; Read paragraph gaps, title blocks, notes/bibliography headings and hanging
  indents inside the sheet. All spacing rules are under `.editor-paper`/`.manuscript-read`
  (document typography, exempt); `.bibliography-page.is-page-view { padding-inline: 0 }` is zero.
- `src/layoutBudget.json`: `"src/components/paged-sheet.css": 0` (the guard asked).
- `src/App.tsx` (regions): reader preference gains `paged` (missing -> true); Read toolbar gains a
  "Page view" `aria-pressed` button; page view renders eyebrow "MANUSCRIPT -- READ ONLY" and Export
  above `<PagedSheet className="read-prose">` holding h1, then per section the `.read-title` button
  (now carrying `id="read-<entry id>"`) and the ReadDocument blocks, then Notes and Bibliography as
  flat blocks. Reader font/size/spacing reach the sheet as `--document-font/size/line` on
  `.manuscript-read`. Page view off = the old markup unchanged (wrapped in a fragment).
  `contentKey` = project id + revision + font + size + spacing (the id so a tab switch between two
  projects at the same revision remounts the surface). BibliographyPage gets the shared preference.
- `src/research/BibliographyPage.tsx`: "Page view" button in `.bibliography-controls`; page view puts
  the controls in a `.bar.bar-main` above `<PagedSheet className="bibliography-entries">` (h1 +
  entries); `contentKey` = project id + revision + order + scope. Off = old markup plus the toggle.
- `tests/fb-paged-read.spec.ts` (new).
- Shared specs (unowned, registered on T330 with `files add`), each test now seeds
  `personal-word.reader` with `paged: false` because it reads the continuous markup; no assertion changed:
  `tests/research.spec.ts` (2 tests: `.reader-footnotes p`, `.reader-bibliography`, `.bibliography-entries > *`),
  `tests/scrollspy.spec.ts` (a) and (l) (`section[id^='read-']` boxes), `tests/floating.spec.ts`
  Read test (one `.read-prose` per section).
