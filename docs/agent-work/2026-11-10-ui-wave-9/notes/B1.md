# W9 B1 -- Font menu

- **Changed:** The document font menu now uses `sameFont` to reconcile equivalent CSS stacks, removes later options for an already-listed family, and displays the unquoted primary family name. The trigger can grow from 124 px to 220 px before truncating long names. Prose check now uses `SpellCheck`; Page setup retains `Settings2`.
- **What users see:** One readable option per family, including after reopening a document whose font value has a quoted CSS stack; Prose check and Page setup have distinct icons.
- **Fail-first evidence:** With the implementation unchanged, `PLAYWRIGHT_PORT=1434 npx playwright test tests/w9-font-menu.spec.ts` failed at the no-quote assertion after the test applied `"Times New Roman", serif` to the selected text. The menu exposed a quoted duplicate for a family already in the built-in list. This is the intended regression failure.
- **Verification:** `npx tsc -b` passed. `PLAYWRIGHT_PORT=1434 npx playwright test tests/w9-font-menu.spec.ts` passed in the isolated acceptance run. After the shared Playwright artifact race, `PLAYWRIGHT_PORT=1434 npx playwright test tests/editor-toolbar.spec.ts --output test-results/T258` passed all 17 tests (2.3m). The isolated rerun had no artifact errors.
- **Limitation:** Browser/Chromium evidence only; no native or screen-taking check was run.
- **Hand check:** In Personal Word, create a blank project, type and select text, choose Times New Roman, then click elsewhere in that text and reopen Font family. Confirm there is one Times New Roman option, with no quote marks, and the full name fits on the button at a 1400 px window. Compare the Prose check and Page setup toolbar icons; they should differ.
