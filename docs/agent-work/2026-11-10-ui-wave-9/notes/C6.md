# C6 -- Installed system fonts

Core Text exposes sorted, non-private installed font families and resolves a requested family/style to its Core Text file URL. The native command returns font bytes and the PostScript name for files up to 30 MB; TrueType/OpenType collections are reported without bytes. The TypeScript adapter returns an empty family list or `null` outside the native app and on command errors, and skips collections.

The commands are registered in both Tauri handler lists. The implementation uses only the locked Core Text/Core Foundation dependencies. Browser preview storage and behavior are unaffected.
