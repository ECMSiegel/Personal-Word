# F5 -- Keep a saved added font when the added-font list failed (T283)

## What changed
`src/fonts/registry.ts` `initFonts`: a rejected added-font list now sets a flag, and the saved font is reset to Futura only when both lists really loaded (installed list non-empty, added list did not fail) and the font is in neither. New unit test in `registry.test.ts`; failing output in `notes/F5-fail-first.txt`.

## What a user sees
One failed read of the added-fonts store no longer permanently loses an added interface font.

## Limitations
No browser run (same code path as T281). Native persistence not tested.

## Hand check
Add a font file in Settings and choose it as the interface font; quit and relaunch: it is still selected.
