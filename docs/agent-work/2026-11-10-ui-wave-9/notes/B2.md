# B2 -- Prose check menu spacing

## What changed
- `src/components/ProseIssues.tsx`: each rule row (Repeated words, Possible passive voice, Filler words, Long sentences) now has its own count next to its label, and the checkbox sits at the end of the row. The long run-on status line is replaced by one short line, "N issues" (or "1 issue" for exactly one). The per-rule counts moved into the rows. Pagination (Previous / Page x of y / Next) renders only when there is more than one page. The inline style on the status line is removed.
- `src/components/prose-issues.css`: the rule rows are a three-column grid (label, count, checkbox), so every checkbox shares one right edge. Checkboxes inside the prose panel get zero margin, because the browser default (4px left, 3px right) pushed them 7px off that edge.
- Each rule checkbox has `aria-label` set to its rule name, so the count does not become part of its accessible name.
- `tests/w9-prose-menu.spec.ts`: new spec, four tests.

## What a user sees
- Prose check rule rows line up as a column: label on the left, its count in grey, checkbox on the right.
- The status line above the list reads "N issues", or "1 issue" when there is exactly one (or "Analyzing prose..." / the unavailable message).
- With 100 or fewer issues there are no Previous or Next buttons.

## Limitations
- The "On" checkbox is rendered in `src/Writer.tsx` (around line 1798), which this task does not own, and was not edited. The zero-margin rule in `prose-issues.css` also applies to it, so its box moves about 3px right to share the edge. The spec checks the alignment.
- The status line now matches the plan's "N issues" wording (rework r4, after review rejection). `tests/writing-aids.spec.ts` line 86 was updated from "2,100 total issues" to "2,100 issues" to match; that file was registered to T259 for this change.
- Hover on a rule row is not a text control, so it gets no grow or weight change; the checkbox does not move.

## Hand check
1. Start the app (`npm run dev`), open a project, turn on Prose check (Aids), tick "On".
2. Type "The the cat." in the editor. Open Prose check: the status line reads "1 issue". The Repeated words row shows 1 and the other three rows show 0.
3. The four rule checkboxes and the On checkbox share one right edge. Hover each rule row: its checkbox does not move.
4. Type about 2,100 repeated words to get more than one page: Previous / Next appear with "Page 1 of 21".
