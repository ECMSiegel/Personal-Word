# F1 -- Sidebar selection spec updated for A1 and C1

## What changed
Spec-only change in `tests/sidebar-selection.spec.ts`. No app code.

1. **Hover grow removed from expectations (W7 Plain test, about line 485).** The open sidebar row
   (`.entry-main`) used to be expected to scale to 1.04 on hover and on keyboard focus. Wave 9 A1
   removed that grow on purpose. The two assertions now read the computed transform scale and expect
   1 (same approach as `tests/hover-emphasis.spec.ts`). The faux-bold stroke assertion is unchanged.
2. **"More details" opened before "Open beside" (B1 test, about line 680).** The attached-PDF field
   now sits inside the collapsed "More details" box (`src/research/SourceForm.tsx`). The spec opens
   that box (only if it is still closed) before clicking "Open beside".

Every other assertion is kept. No test was deleted or skipped.

## Fail-first evidence
The tests were already failing before this change, so no new fail-first run was made. The failing
output is saved in `docs/agent-work/2026-11-10-ui-wave-9/notes/A3-acceptance-r5.txt`. It shows the
W7 Plain test at line 485 failing, and the four B1 palette tests at line 622 failing after 1.5 minutes
(the timeout near the "Open beside" click).

## What a user sees
Nothing changes in the app. The spec now matches the current app: a hovered sidebar row keeps its
faux-bold stroke but does not grow, and the source PDF button is reached by opening "More details".

## Limitations
- The spec opens "More details" by clicking its summary. If the box is already open, it is left open.
- The "Open beside" check still runs only in light and dark, plain and color palettes, as before.

## Exact hand check
1. Start the dev server on port 1447 and run:
   `PLAYWRIGHT_PORT=1447 npx playwright test tests/sidebar-selection.spec.ts --output test-results/F1`
   Expect all tests to pass.
2. In the app: create a research source, choose "Enter manually", attach a PDF in the More details
   section, then click "Open beside" after opening More details. The PDF pane should open beside the
   manuscript.
3. Hover an open sidebar row. The text should go bold-looking (stroke) without growing.
