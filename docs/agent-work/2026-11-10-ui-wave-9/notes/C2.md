# C2 -- Font storage in the native app

Implemented native commands `font_add`, `font_list`, `font_read` and `font_remove`. Font bytes and
an atomic JSON index are stored in the `fonts` directory beside the project database. Added checks
for supported file types and magic, 20 MB size limit, safe family/style values, duplicate
family/style pairs, and IDs that are not in the index. Added temporary-directory tests for storing,
listing, reading, removing, validation failures and multiple styles of a family.

**User sees:** added fonts can be persisted in the native app, independent of browser-preview
storage. This task does not wire the Settings UI; that is C3.

**Limitation:** font metadata (family and style) is supplied by the caller and is not parsed in
Rust. The uploaded font file itself is not validated beyond its extension, size and four-byte magic.

**Hand check:** in the built Mac app, add a `.ttf` or `.otf` font in Settings > General, quit and
reopen Personal Word, and confirm the family is still listed and usable. Remove it and confirm it
disappears. Do not use a native screen script for this task.
