# W9 B6 -- PubMed, PMC and PMID lookup

- **Changed:** `lookupIdentifier` now accepts PMID-prefixed identifiers and PubMed article URLs, and routes PMC article URLs through NCBI ESummary. It follows an article's DOI to Crossref when available, otherwise builds a journal-source draft from the NCBI title, authors, journal, volume, issue, pages and publication year. A failed NCBI request for a PubMed/PMC URL falls back to the existing page-metadata lookup. A bare number is not treated as a PMID.
- **Fail-first evidence:** Before the implementation, `npx vitest run src/research/lookup.test.ts` reported 7 failed tests (PMID prefixes rejected, PubMed/PMC URLs handled as ordinary pages, and the NCBI fallback path absent). These failures exercised the requested missing behavior.
- **Verification:** `npx vitest run src/research/lookup.test.ts` passed (22 tests). A one-time live request to NCBI ESummary for PMID 33301246 confirmed the expected `result[uid]` record shape, including `authors`, `pubdate`, `fulljournalname` and a DOI `articleids` entry. `npx tsc -b` was also run, but reports a TypeScript error in `src/editor/blankClick.test.ts:54` (outside this task's registered files); no error was reported in the lookup files.
- **Limitation:** Browser and unit evidence do not verify native WebKit or a user's real library. Rust lookup code and its user agent were not changed.
- **Hand check:** In the built app, paste the owner's PubMed link for the Gupta article into Research lookup. Confirm it creates the expected journal source, follows the DOI when one is available, and falls back to page metadata if NCBI cannot be reached.
