## Plan versus code

  on the root and passed as pixels (fallback `16px`).
- The animation is `fill: none`; the aside's width/layout is final on the first frame because only
  transform and opacity move (test checks `.writer-scroll` width equals its final width at the first
  frame the aside exists).
- eslint-disable comment on the hook's deps: `wasPointer` reads a ref and must not retrigger the effect.
