# P1 -- Projects page (T274)

## What changed
- `src/components/ProjectLibrary.tsx`, `src/components/library.css`: the toolbar row now holds only Start new project, Import writing, the search and the gear. Sort, the reverse button and the list/cards toggle moved to a quiet caption row (`.library-caption`) directly above the list: 12 px, muted colour, no outline. The reverse and view buttons are `icon-button icon-grow` (the reverse arrow is an `aria-hidden` span inside the button). The search button, the gear and the row trash also carry `icon-grow`; the trash keeps `delete-entry`.
- Rows: the title is 15 px (`--type-large`) and first; "Edited <date>" follows in the normal text colour, then "Added <date>" muted (the old "--" separator and "Last Edited" wording are gone). Cards use the same order.
- `src/libraryPreferences.ts` (+ unit test): `{ sort, reverse, view }` under `folio.workspace.library`, tolerant of missing or bad data field by field. Sort, direction and view are read on load and written on every change.
- Empty state: "Start with a blank page or a template, or bring in writing you already have." plus text controls Blank, Chicago, Screenplay (the same list the Start menu uses) and Import writing. Templates call the same create action as the menu; Import writing opens the same writing picker as the menu's "Import a file...". No illustration. "No matching projects." for an empty search is unchanged.
- `tests/w9-projects-page.spec.ts` is new. `tests/projects-screen.spec.ts` needed no re-pin: nothing in it located Sort or the view toggle (the gear and search stay in `.library-display`).

## What a user sees
Projects page: create / import on the left, search and gear on the right. Under them, a small grey "Sort  Last edited v   arrow   view" line sits just above the list. Pick a sort, flip direction or switch to cards, close the app, come back: the page is the same.

## Limitations
- The empty-state buttons have accessible names "Start a Blank project", "Start a Chicago project", "Start a Screenplay project", "Import writing from a file" (visible text is the short word). Reason: the Start menu's items are named exactly "Blank", "Chicago" etc., and many specs click those with exact names; duplicate names would break them.
- The Sort dropdown button is a text control, so the shared hover rule still gives it the faux bold on hover/focus (that rule lives in `src/styles.css`, not owned here). At rest it is not bold and has no border or outline.
- The caption row is shown even with no projects (motion.spec opens Sort on an empty list).

## Hand check
1. Open Projects with two or three projects. Confirm the toolbar has four controls and the grey caption row sits above the list.
2. Choose Sort > Name, press the arrow, press the cards icon. Reload (or restart the app): same sort, direction and view.
3. Hover the arrow, the cards icon, the magnifier, the gear and a row trash: each icon grows slightly, nothing shifts.
4. Check a row: bigger title, "Edited ..." in normal colour, "Added ..." grey.
5. Delete all projects: one sentence plus Blank, Chicago, Screenplay and Import writing; each does what the Start menu item does.
