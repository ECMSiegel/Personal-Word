## 5. Optical vs geometric alignment (principle + how to encode/verify)
Rule: start from the box, then nudge the glyph so its visible edge/visual centre lands where the eye expects, and record the nudge once as a token or fixed asset. Cases: (1) icon+label buttons: less padding on the icon side (16/14) because Lucide's 24-grid glyphs carry ~2 px blank per side (~1.3 px at 16 px); (2) trailing arrows: make the visible gap arrow-ink -> edge equal the text-left gap -- NOTE Lucide `arrow-right` ink spans x=5..19/24, leaving ~3.3 px blank on the right at 16 px, so a box-centred layout needs LESS right padding, not the +4 px from the owner's screenshots (that example used a different glyph): measure ink, don't copy signs; (3) triangles/play: centroid sits 1/3 from the base; shift ~1-3 px toward the point (Lucide `play` needs <1 px at 16 px); (4) rows: align on the text's left edge with a fixed-width icon slot; centre vertically on cap/x-height; `text-box: trim-both cap alphabetic` where supported (Chrome 133, Safari 18.2; feature-detect with `CSS.supports`, padding fallback; WKWebView depends on macOS); (5) `font-variant-numeric: tabular-nums` on changing numbers (check Futura has `tnum`: width("111")===width("888")); (6) circles/badges look low-right; large T/F/P look indented. Encode: fix the SVG first; icon box with transparent padding + `transform: translateX(var(--optical-x,0))` (static transform is allowed); `--optical-*` component tokens with a table in design-system.md; shared icon-slot width; text trimming. Verify in Playwright: union of `getBBox()` through `getScreenCTM()` (+ half stroke) = ink rect; assert |inkCentre - containerCentre| <= 0.5 px; centroid for triangles; gap equality via `Range.getBoundingClientRect()`; one unique label-x across sidebar rows (0.5 px); tabular check; prove it fails on a +4 px doctored copy; Chromium != WKWebView -- view native PNGs at 4x. Sources: UI/UX Atlas optical-vs-geometric lesson, jakub.kr "Details that make interfaces feel better", Chrome blog on `text-box-trim`, Figma forum thread on optical centring, Material system icons.
