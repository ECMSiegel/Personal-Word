# T12 (board T316) -- Header colour from the right-click menu, for every header

## What the owner sees
- Palette = Color: right-click (or Shift+F10 on) any top-level header -- Manuscript, Fragments, Research or a
  custom one -- and the menu ends with a thin rule and one row of eight coloured squares (Red, Orange, Yellow,
  Green, Teal, Blue, Indigo, Purple). The current colour has a thin outline around it. Click a square: the
  header's icons change at once, the menu closes, focus goes back to the heading.
- Keyboard: Up/Down treat the row as one stop; Left/Right move between squares (wraps); Home/End jump to the first
  or last square while on the row; Enter/Space pick; Escape closes.
- Colours are PER PROJECT (owner decision relayed by the coordinator mid-task): changing Fragments in project A
  does not change project B. A project that never had a colour picked shows the old app-wide colours from
  Settings, so existing projects look the same as before. A custom header with no colour shows the project's
  Manuscript colour (and that square is the marked one).
- Palette = Plain: no rule and no colour row.
- Gone: the "Colour…" menu item and its "Header colour" dialog; the "Header colours" row (three dropdowns) in
  Settings > General.
