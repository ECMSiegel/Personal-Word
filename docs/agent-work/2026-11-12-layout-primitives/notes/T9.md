# T9 (board T313): Header naming and per-header colour

## What changed
- Custom top-level sidebar sections are called "headers" in every visible string. Entry-level "section" wording is untouched.
- A custom header has an optional colour (`Project.groups[].colour`, one of the eight swatches). Its heading menu has "Colour…", which opens a small "Header colour" dialog (swatch dropdown with "Default"; in Plain palette a one-line note says colours show when Palette is Color).
- The sidebar group carries `data-tint="<swatch>"`; `src/styles.css` maps it to `--tint` only in Color; unset = Manuscript's tint. Built-ins never get it.
- Data: `validateProject` drops an unknown colour (never rejects). The colour round-trips through archive, save queue and snapshots (model.test.ts, groups.test.ts). Rename keeps it; delete removes it with the group.
- Rust: `groups` lives in the flattened `extra` map, so the key round-trips; the store.rs fixture line carries `"colour":"purple"`. cargo test was NOT run (needed).

### Rework (review REJECT, REVIEW-5)
- Bug: in the Header colour dialog the swatch Dropdown sat inside `<label className="stack gap-2">`. The Dropdown list renders inline (no portal), so the option click was forwarded by the label to the trigger button and the list reopened over the dialog after every choice.
- Reproduced first: the new assertion `expect(page.getByRole("option")).toHaveCount(0)` after choosing Purple failed with 9 options still visible (notes/T9-rework-fail-first.txt). Cause confirmed as the review said.
- Fix (src/App.tsx, colour dialog only): `<label>` -> `<div className="stack gap-2">`, title in a `<span>`. The Dropdown keeps its accessible name "Colour" (its own `aria-label`), so the test selector is unchanged.
- Test: hs9 colour test also checks the trigger shows Purple, and takes light and dark screenshots of the dialog with the list closed.
- Low: the empty-space context menu's accessible name "Sections actions" -> "Sidebar actions" (ProjectSidebar.tsx). No test or doc referenced the old string.
- Not touched (pre-existing, for the coordinator): same label-wrapped Dropdown in `src/organization/RevisionComparison.tsx:55`.
