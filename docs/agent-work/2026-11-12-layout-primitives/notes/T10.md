# T314 (LP T10): Dropdown inside a `<label>` re-opened after a mouse pick

## Origin: PRE-EXISTING (not caused by this batch)
`git show 1361f1e:src/components/Dropdown.tsx` vs now: options were already `<div role="option">` with `onClick={() => choose(index)}` and no `preventDefault`, and the list was already rendered inside the wrapper (Popover is not portalled). The batch diff only changes classes (`menu`, `row`, `menu-rule`, `row-label`, `row-trail`), so no behaviour that blocks label forwarding was removed. A click on non-interactive content inside a `<label>` is forwarded to the label's first labelable descendant, the trigger button, which re-opens the list.

## Fix
`src/components/Dropdown.tsx`, option `onClick`: `event.preventDefault()` before `choose(index)`. A click whose default is prevented does not trigger label activation. Trigger name (`aria-label`), keyboard, focus return, typeahead untouched. No call site edited.
