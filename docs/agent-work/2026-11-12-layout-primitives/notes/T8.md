# T8 notes (Comments, fragments, revisions) -- rework of T312 after REVIEW-2

## What changed
Spacing now comes from the primitives on the markup; the per-component declarations are deleted.
- Comments panel (`CommentsPanel.tsx`, organization.css): section `.stack.gap-5`, header `.cluster.gap-4`,
  each comment `.stack.gap-2`, its checkbox label `.cluster.gap-2`, its buttons in a `.cluster.gap-3`
  (button padding 8/12 -> 0, so the links sit on the text's left edge 12 apart). Each item pads only
  BELOW its divider (`padding-bottom: --space-5`); the panel's 24 gap is the space above the next one,
  so dividers have 24 above and 24 below (was 24/32). No wrapper div needed. Deleted: header gap,
  `small` margin, checkbox margin-right, button padding. `.feature-panel h1` margin set to 0.
- Fragment library (`FragmentLibrary.tsx`, fragments.css): library `.stack.gap-3` with `--edge: 0px`;
  controls `.cluster.gap-3` (wrap kept); "All projects" `.cluster.gap-2`; item `.stack.gap-2` with
  padding-bottom only (dividers 12/12, same trick); head `.row` with `h2.row-label` and the chevron a
  `.slot.row-trail` (32 px row, chevron centred); actions `.row.gap-3` (12, chosen deliberately: the
  previous `.row` had silently made it 8); trash `.slot.row-trail`, so it shares the chevron's right
  edge; tags `.cluster.gap-2`. Deleted count/empty margins, item gap/padding-top, head display/gap,
  actions display/gap/--edge, icon padding 2 px, tags/across/controls display/gap. "Show all" now sits
  left (`align-self: flex-start`) instead of stretching. Fragment TEXT typography untouched.
- Revision comparison (`RevisionComparison.tsx`, organization.css): `.revision-comparison`,
  `.revision-oversized` and `.revision-selected-passage` are `.stack.gap-3`; both
  `.revision-change-controls` are `.cluster.gap-3`. Deleted the controls margin, the selected-passage
  margin, the "Restore this section" margin-top and the help-text margin-top. Buttons that are direct
  stack children keep their own width (`align-self: flex-start`). `.revision-comparison` has
  `padding-bottom: --space-5` because the stack drops the help text's bottom margin (screenshot showed
  the following "Opening" heading touching it).
- Reader options (App.tsx, className lines only): `.cluster.gap-3`, labels `.cluster.gap-2`; their
  display/gap declarations deleted. margin-bottom 24 KEPT: the parent `.manuscript-read` (styles.css)
  is not a stack and is not this task's; making it one would touch Read-mode/floating geometry.
  Note: App.tsx is listed as shared in BRIEF but the board shows T311 holding it; I edited only the
  four reader-options className lines with Edit.
