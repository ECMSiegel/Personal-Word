# PLAN -- Source-alpha security, reliability, and sidebar selection
Date: 2026-10-19 | Architect: Codex | Status: APPROVED -- owner: “Approved. Start” (2026-10-19)

## Goal
Writers can use sidebar controls without accidentally selecting the interface, and the local source-alpha tag identifies reviewed source with honest security and reliability evidence.

## Request
“Write a plan for Luna agents to do: security/reliability review → address findings and sidebar highlighting → finalize the evidence commit/tag.” This turn authorizes PLAN.md only; no implementation, scans, installation, commits, account connection, or push.

## Definition of done
- The exact intended public source and main-branch history have a redacted, bounded security/privacy review; current npm and Rust dependency advisories are assessed.
- Confirmed in-scope defects have behavioral regressions seen failing before repair and passing afterward. No unresolved release-blocking findings or silently waived checks.
- Sidebar chrome cannot acquire accidental native text selection; search/rename fields, manuscript, fragments, and research prose remain editable/selectable; navigation, drag reorder, resize, focus and keyboard access survive.
- Required automated qualification passes on final code; actual light/dark screenshots, native sidebar behavior and isolated native recovery results are inspected or owner-confirmed. Unavailable required checks remain BLOCKED, not complete.
- The four existing browser-evidence document edits are preserved and attributed to the owner's 46/46 Terminal run. New code changes receive fresh testing.
- Independent review approves; the session's intended files are committed with existing noreply identity, and local annotated v0.1.0-alpha.1 points to the final evidence commit. Previous tag is recoverable, source/code tested equals source/code tagged, working tree is clean, HANDOFF.md remains ignored, no remote/push occurs.

## Non-goals
GitHub installation/authentication, remotes/pushing/publishing; beta/1.0 feature development; signing/notarization or distributing binaries; cloud/accounts; general App/Writer refactoring; exact editor/export pagination parity; new fonts/UI redesign; automatically changing dependency major versions; deleting projects, recovery data, old bundles, Git history or internal app refs. Word/LibreOffice review beyond any changed export behavior remains an explicitly documented release limitation.
