# UI wave 4 H1 -- hover inventory

Task T172. Source: static grep of every stylesheet plus the crawler `tests/hover-emphasis.spec.ts` (helper `tests/hover-helpers.ts`) run on the untouched wave-3 tree (`9d7cd40` + working tree, Chromium, 1440x900, light). Status words: CLAIMED (crawled and recorded, not owner-confirmed).

Totals: 1246 control instances (549 text, 697 icon-only) over 20 screens, collapsing to 104 distinct selector shapes (76 text, 28 icon). Hover is sampled once per shape (computed style is class-driven) 30 ms after the pointer lands, so `transform` still reads `none` where a transition would be in flight; H2 uses 200 ms. The full per-instance table is regenerated by the spec to `node_modules/.cache/personal-word-beta/ui4-h1/crawl-table.md` (not committed).

Headline findings:

- Of 76 text-control shapes, 60 do nothing at all to weight or size on hover; 16 already go to weight 600 through their own selected/current/hover rule. **No control anywhere scales on hover** (`transform` is `none` on hover for every sampled shape). So every text control lacks the new bold+grow treatment.
- Owner-reported controls confirmed missing: `Delete note` (`button.is-danger` in a note item), `Snapshot` (`button.snapshot-button`), top bar `Projects` tab button, `Open beside`, `Remove PDF`, `Delete source`, `Cite here`, `Add quote`, `Insert at cursor`/`Append to section` (`button.fragment-link`), `Create snapshot`, every settings button/label, the Dropdown triggers (`100%`, `Normal text`, `Futura`), `Keep as fragment`, and the dialog `Cancel`.
- Text controls that are not `button`/`a`/`summary`: `label:has(input)` rows (`.settings-check`, `.settings-field`, `.check`, `.fragment-across`, `.fragment-tags`, `.reader-options label`) and the dialog `label`. Decide in H2 whether the catch-all should include checkbox labels (the plan list says it does; H2/H3 must verify a label wrapping a text input, e.g. `Total word goal`, does not jump on hover).
- Rows that go bold on hover today by their own rule (to delete in H2/H3, listed below): sidebar group titles and entry rows, project-name in the project list, Popover items, Dropdown options (via `[data-highlighted]`/`.is-highlighted` in popover.css), `.template-choice strong`.
- Possible width jumps: `font-weight` hover changes glyph widths; `.tabs-library`, `.project-tab`, `.snapshot-button`, `.breadcrumb-title` (inside `overflow: hidden; text-overflow: ellipsis` `.breadcrumb`) and the `Normal text`/`100%` dropdown triggers are the ones most likely to wrap or clip -- H2 step 4/Stop-and-ask applies.
