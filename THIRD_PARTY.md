# Third-party software and license inventory

The project source is licensed under GPL-3.0-only. The machine-readable lockfile inventory is [docs/dependency-licenses.json](docs/dependency-licenses.json); regenerate it from the repository root with Python 3.11 or newer:

```sh
python3 scripts/license-inventory.py
```

It records 254 npm lockfile packages: 99 production (including 5 optional platform-specific packages) and 155 development. All 254 have license metadata in `package-lock.json`. The npm inventory preserves SPDX expressions as published in the lockfile. One transitive dependency, `jszip` 3.10.2, declares `(MIT OR GPL-3.0-or-later)`; the project can select its MIT option. Other direct runtime libraries include React and Tiptap (MIT), `docx`, `pdf-lib`, and `@pdf-lib/fontkit` (MIT), `markdown-it` (MIT), Lucide React (ISC), and Tauri's API and dialog packages (Apache-2.0 OR MIT). The Tauri CLI, TypeScript, Vite, Playwright, and test/build tools are development dependencies, as marked in the inventory. `markdown-it` 15 ships its own type declarations, so no separate `@types/markdown-it` package is installed.

The PDF exporter embeds WOFF2 font subsets from three `@fontsource` packages: `@fontsource/noto-serif`, `@fontsource/noto-sans`, and `@fontsource/noto-sans-mono` 5.3.0, all OFL-1.1. The font files are Noto Serif, Noto Sans, and Noto Sans Mono (Google/Adobe, OFL-1.1). Their OFL license text ships in each installed package's `LICENSE` file, but the built application bundle embeds the subset bytes without a notice file; a distributed binary therefore needs the OFL notices and license text added to it explicitly. OFL-1.1 also reserves the fonts' own names for modified versions; the bundled files are unmodified subsets of the published packages.

The Cargo inventory records 456 non-workspace packages from `src-tauri/Cargo.lock`. The generator reads exact-version manifests from the local Cargo registry cache only. In the current inventory, all 456 manifests are available and provide license metadata. If a future local cache is incomplete, missing exact-version metadata is reported; run `cargo fetch --locked --manifest-path src-tauri/Cargo.toml` and regenerate to fill those records. The source does not contain absolute cache paths. Direct Rust dependencies include Tauri and its dialog plugin (Apache-2.0 OR MIT), `rusqlite` (MIT), Serde, Chrono, libc, UUID, and ureq (MIT OR Apache-2.0); `tempfile` is an MIT OR Apache-2.0 development dependency. `tauri-build` is recorded as a build dependency. Cargo lockfiles do not fully determine target and feature activation, so the inventory identifies direct runtime, build, and development roles and leaves transitive roles unclassified.

Several dependency expressions deserve explicit notice handling. `jszip` offers MIT or GPL-3.0-or-later; this project selects its MIT option. `r-efi` offers MIT, Apache-2.0, or LGPL-2.1-or-later; the MIT or Apache-2.0 option avoids relying on the LGPL option. Five Rust crates declare MPL-2.0 (`cssparser`, `cssparser-macros`, `dtoa-short`, `option-ext`, and `selectors`). MPL 2.0 section 3.3 permits a larger work under GPL terms if the covered files are not marked “Incompatible With Secondary Licenses”; retain the crates' MPL notices and check the actual source/binary bundle notices. The cached license texts inspected contained standard MPL terms, and the registry search found no separate incompatibility notice. GNU's MPL 2.0 guidance describes this GPL compatibility and its condition in [the license list](https://www.gnu.org/licenses/license-list.html#MPL-2.0). `caniuse-lite` carries CC-BY-4.0 data, `webpki-roots` uses CDLA-Permissive-2.0 for root data, and `sax` declares BlueOak-1.0.0; preserve their applicable notices and attributions. These are flagged for notice review, not identified here as GPL incompatibilities.

The UI refers to Futura and Avenir by system font name with system fallbacks; no proprietary font files are bundled in the source tree. The `rusqlite` `bundled` feature compiles SQLite into the native application. This source inventory does not establish the contents or notice obligations of a built app bundle. Before distributing binaries, inspect the actual bundle and provide all required third-party copyright and license notices, including notices for compiled or platform-provided components. This document and the generated metadata are not a legal opinion or a complete binary notice package.
